# QuickNotes App
## Description
QuickNotes is a simple note-taking web application that allows users to create, organise, search and delete notes. Users can categorise their notes into Personal, Work and Study categories. The application also saves notes in the browser using localStorage so they remain available after refreshing the page.

## Features
- Add notes with different categories.
- Delete individual notes.
- Search notes using keywords.
- Validate notes to prevent empty notes and notes longer than 200 characters.
- Display the total number of notes.
- Automatically save notes using localStorage.
- Responsive layout for different screen sizes.

## How to Run Locally
1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server or your browser.
4. Start creating and managing your notes.
